64 native tools

I checked the inventory with node scripts/test-local-tools.mjs --list. The tool harness is a CI guard; it does not call a model. All eight tests pass in 1.4 seconds.

What the harness checks

  • Arguments: Object key order does not matter, but array order and changed values do. It also distinguishes invalid JSON from arguments that fail the tool schema.
  • Inventory: The expected native tools are present. The coverage report checks that all 64 have handler tests.
  • Fixtures: Generated arguments validate correctly for supported schema shapes, including optional and nullable values.

Why I said 88 earlier: I counted registration lines in source code. Some lines register several tools and some registrations span several lines. The CLI inventory’s count of 64 is authoritative.
