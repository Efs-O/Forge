Three separate launches stacked into one panel to save space. This is the argument: the block is worth reading because it is different each time.

Why this beats a logo

Ready vs loading is the gap between an instant reply and a 40-second model load. Right now that costs you a send and a wait to discover.

And it still does the branding job — the mark is right there, just not doing all the work alone.

Why Claude and Codex can't

They talk to a hosted endpoint. No local process, no VRAM, no context window you configured. Their empty screen has nothing true to say, so a mark is the only honest thing to put there.

Forge drives a llama-server you spawned with flags you chose. It has facts.

What it costs

No new host plumbing. App.tsx already holds all three values — ModelsMsg.residency, TokenBudgetMsg.max (that's perSlotContext(), already dividing by n_parallel), and backendDown.

It's a presentational component reading the reducer. Gone the moment the first token lands.

Tab 1 on the local model, tab 2 on a cloud provider. Concurrency 1 is a VRAM fact, not an architecture fact — and it stops being true the moment one tab is cloud, or you spawn with --parallel 2.

They're parallel context, not parallel execution

You're right that one slot means one turn. But tabs give you three separate histories you switch between without compacting or losing state — and that is exactly what a single-threaded CLI cannot do.

That value holds even at concurrency 1.

The code already assumes N

streamingIds is a Set, not a single id — TurnLifecycle.ts:37. Queued prompts are keyed per conversation. The ceiling isn't the UI.

Don't design a temporary constraint in permanently.

If you do collapse to one tab

The spinner is currently suppressed on the active tab — live && !sel in TabStrip.tsx:171 — because StreamingStatus covers the foreground turn.

Collapse the strip and that condition has to go, or the indicator vanishes exactly when you need it.

What's missing, exactly

Then reuse .tab-streaming-spinner. No new CSS.

Two marks, two meanings

Spinner = generating. Static amber dot = waiting on you.

If a tab is blocked on the confirmation gate, a spinner is a lie — it says the machine is busy when it's actually you that's holding things up.

Accessibility comes free

tabs.css:227 already kills the animation under prefers-reduced-motion. Keep that on any new indicator — under reduced motion the ring becomes a static accent circle, which still reads.
