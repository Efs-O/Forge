A · What ships today — the baseline

A square-cornered solid block on --vscode-button-background. It reads as a form submit from a settings page, and it is the only element in the row that does — the remote chip and the model selector are both pill/rounded and lightly tinted. That mismatch is what looks dated, more than the button itself.

1 · Circular icon — smallest footprint

Arrow only, no word, on a filled accent circle. This is the shape Claude, ChatGPT and Cursor all converged on. It buys the most horizontal room — worth something in a sidebar that also has to fit a model name and a remote chip — and the disabled state is legible at a glance because the fill drains to grey. Cost: the affordance is entirely iconographic; the title tooltip is the only text. The narrow-width rule that currently hides the word becomes unnecessary.

2 · Outlined pill — matches the remote chip

Same construction as the remote chip already sitting on the other side of the row: 1px accent border, 10% accent fill, accent text, pill radius. The row becomes one visual family — chip, selector, button — reading left to right at the same weight. Cost: it is quieter than a filled button, so Send stops being the loudest thing in the composer. In a panel where Enter already sends, that is arguably correct; if you want the button to pull the eye, take 3 instead.

3 · Solid accent pill — closest to today, modernised

Keeps a filled button and the word, but on --forge-accent rather than VS Code's stock button blue, with a pill radius and slightly tighter padding. This is the minimum-risk change: nothing about how the control reads is altered, it just stops looking like a dialog's OK button. Cost: it is now the same blue as the remote chip while doing a completely different job, so the two compete a little on a narrow panel.

4 · Flat with keycap — teaches the shortcut

No chrome until hover, with an inline ⏎ keycap that says what the button is a slower version of. The composer hint line below currently spends its whole width repeating "Enter to send" — this puts that fact on the control it belongs to, and frees the hint for the Shift+Enter half alone. Cost: the lightest of the four; on a busy panel it can read as disabled until hovered, and the keycap needs the narrow-width rule to survive at 320px.
